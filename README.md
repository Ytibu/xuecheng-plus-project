# 黑马学成在线课程代码（后端）

## 项目结构
- xuecheng-plus-auth        用户认证系统
- xuecheng-plus-checkcode   认证图形校验码
- xuecheng-plus-content     内容管理系统
- xuecheng-plus-learning    课程学习系统
- xuecheng-plus-media       媒资管理系统
- xuecheng-plus-orders      课程订单模块
- xuecheng-plus-search      基于ES的搜索模块
- xuecheng-plus-base        项目工具
- xuecheng-plus-gateway     微服务网关
- xuecheng-plus-system      词典系统模块
- xuecheng-plus-message-sdk RabbitMQ消息封装件
- xuecheng-plus-parent      Maven项目依赖的父模块
- xuecheng-plus-generator   代码生成目录（可直接省略，生成的代码已经被其他模块使用）
